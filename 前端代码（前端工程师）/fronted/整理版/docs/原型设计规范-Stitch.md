## Brand & Style

The design system establishes a rational, poised, and hyper-transparent financial management experience. The core design thesis centers on "budget penetration into every transaction"—empowering users with real-time financial clarity the exact instant an expense is logged. 

The emotional tone balances analytical control with psychological calmness. Traditional personal finance tools induce unnecessary friction and anxiety by painting every expense in aggressive reds. In contrast, this design system treats spending as a natural, systematic operation, framing financial management not as punitive restriction, but as intentional resource allocation.

### Design Movement: Modern Analytical Calm
The aesthetic combines Scandinavian-inspired clarity, Swiss functional typography, and subtle modern atmospheric elevation:
- **Clean Whitespace & Precision:** Generous breathability that reduces visual noise across complex financial states.
- **Cool Slate Tonal Architecture:** Replacing murky neutral grays with crisp, slate-tinted undertones that echo calm precision and digital clarity.
- **Tactile Soft Surfaces:** Controlled rounded structures (16px to 24px) that soften analytical density while maintaining absolute geometric discipline.

## Colors

The color palette is deliberately calibrated to preserve cognitive bandwidth and prevent ledger fatigue. Financial indicators strictly observe functional semantic boundaries.

### Primary & Accent Spectrum
- **Primary (Teal):** 
  - `brand-50` (`#F0FDFA`): Atmospheric tint, active table row highlights, positive badge backdrops.
  - `brand-100` (`#CCFBF1`): Subtle borders on active elements, indicator tracks.
  - `brand-500` (`#14B8A6`): Interactive accents, secondary icons, linear gradient start.
  - `brand-600` (`#0D9488`): Primary brand anchor, income values, selected tab indicators.
  - `brand-700` (`#0F766E`): High-emphasis primary CTA buttons, active state press fills.
  - `brand-800` (`#115E59`): Deep contrast text within brand-tinted surfaces.
- **Secondary (Cyan Accent):**
  - `accent-50` (`#ECFEFF`): Information callouts, soft meter tracks.
  - `accent-500` (`#06B6D4`): Linear gradient terminal color, auxiliary analytics graphs.
  - `accent-600` (`#0891B2`): Focus rings, contextual data highlights.
  - `accent-700` (`#0E7490`): Deep cyan for interactive auxiliary links.
- **Brand Hero Gradient:**
  - `linear-gradient(135deg, #14B8A6 0%, #06B6D4 100%)`: Reserved strictly for high-hierarchy anchor surfaces, specifically the "Daily Safe Spend" status widget.

### Neutral Palette (Slate Cool Grays)
- **Canvas Base (`slate-50`):** `#F8FAFC` — Root app canvas, providing subtle contrast against elevated cards.
- **Surface Elevation (`pure-white`):** `#FFFFFF` — Primary card container background.
- **Sub-Surface Tier (`slate-100`):** `#F1F5F9` — Input field fills, segmented control tracks, disabled buttons.
- **Structural Outlines (`slate-200`):** `#E2E8F0` — 1px crisp dividers, inactive borders.
- **Placeholder & Ghost (`slate-400`):** `#94A3B8` — Form placeholder copy, inactive icons.
- **Secondary Prose (`slate-500`):** `#64748B` — Category labels, timestamps, transaction metadata.
- **Primary Text & Expense (`slate-900`):** `#0F172A` — All primary headings, critical values, and regular expense amounts.

### Crucial Semantic Ledger Rules
1. **Expense Non-Red Principle:** Expense figures are rendered strictly in `#0F172A` (`slate-900`). Normal daily consumption is an expected reality, not an emergency.
2. **Income Positive Encoding:** Income amounts leverage `#0D9488` (`teal-600`) to signal resource inflow cleanly.
3. **Emergency Red (`rose-600` `#E11D48`):** Restricted solely to budget exhaustion, negative balance breaches, or destructive operational confirmations.
4. **Cautionary Amber (`amber-500` `#F59E0B`):** Reserved for warning thresholds (e.g., category budget consumed beyond 85%).

## Typography

**Manrope** serves as the exclusive typeface family across all screen sizes and interfaces. Its geometric construction, open apertures, and modern neo-grotesque proportions grant superior legibility for both condensed tabular figures and expansive analytical dashboards.

### Numerical Typography Discipline
Financial applications depend decisively on numerical rhythm:
- All numerical metrics and currency quantities must activate CSS open type feature `tnum` (tabular figures) to enforce monospace alignment across lists and tables.
- Decimal points and fractional currency amounts scale proportionally to 80% opacity and 1 step down in typographic hierarchy to keep primary currency figures dominant.
- Currency symbols (¥, $, €) sit at `fontWeight: 500` and margin right by `2px` from the value.

## Layout & Spacing

The layout operates on a strict 4px base increment grid, prioritizing thumb-zone reachability on mobile devices while expanding gracefully into multi-column balance on larger viewports.

### Grid Infrastructure & Adaptation
- **Mobile Handheld (< 640px):**
  - Single primary vertical stack with a max container width of 480px.
  - Screen outer margin: `1rem` (16px).
  - Component gap: `0.75rem` (12px) to `1rem` (16px).
  - Floating bottom bar / action trigger elevated `1rem` off screen base with safe area padding.
- **Tablet & Compact Desktop (640px – 1024px):**
  - 8-column fluid grid with `gutter` of `1.25rem` (20px) and `margin-md` of `1.5rem` (24px).
  - Top hero metrics split into 2 horizontal analytical cards.
- **Desktop Dashboard (> 1024px):**
  - 12-column grid capped at a maximum width of `1200px`.
  - Left persistent navigation (col 1–3), primary ledger stream (col 4–8), contextual budget penetration sidebar (col 9–12).
  - `gutter-lg` set to `1.5rem` (24px) and outer `margin-lg` set to `2rem` (32px).

### Spacing Tokens Application
- `space-xs` (4px): Icon-to-text gap, badge internal vertical padding.
- `space-sm` (8px): Stack gap between title and subtitle, compact chip padding.
- `space-md` (16px): Standard internal card padding, input field padding, item row separation.
- `space-lg` (24px): Hero card internal padding, section breaks.
- `space-xl` (32px): Major analytical group boundaries and bottom sheet clearances.

## Elevation & Depth

The design system minimizes dramatic dropshadows in favor of structured surface tiers and diffused, cool-tinted ambient glows. Visual hierarchy relies primarily on light and crisp tonal layering.

### Surface Architecture
- **Base Canvas:** Pure `#F8FAFC`. It establishes a cool, high-efficiency ground plane.
- **Tier 1 (Surface Cards):** `#FFFFFF` paired with an ultra-delicate outline `border: 1px solid #E2E8F0` and an ambient shadow: `box-shadow: 0 1px 3px 0 rgba(15, 23, 42, 0.04), 0 1px 2px -1px rgba(15, 23, 42, 0.02)`.
- **Tier 2 (Hero Atmospheric Gradient):** The core "Daily Safe Spend" surface features a solid `135deg` brand gradient tinted with cyan highlights. It projects a soft directional ambient floor glow: `box-shadow: 0 12px 24px -6px rgba(20, 184, 166, 0.25)`.
- **Tier 3 (Floating Action & Overlays):** Action overlays, rapid-entry keypads, and bottom sheets leverage pure `#FFFFFF` alongside an elevated ambient shadow: `box-shadow: 0 20px 25px -5px rgba(15, 23, 42, 0.08), 0 8px 10px -6px rgba(15, 23, 42, 0.04)`.
- **Backdrop Blur:** Modals and bottom sheets utilize a scrim of `rgba(15, 23, 42, 0.35)` with `backdrop-filter: blur(8px)`.

## Shapes

The interface balances precision and warmth through generous, continuous curvature:
- **Card Containers & Modules (`rounded-2xl`):** Exactly `1rem` (16px) radius on standard mobile cards, stepping up to `1.25rem` (20px) on large hero cards.
- **Form Inputs & Action Buttons (`rounded-xl`):** `0.75rem` (12px) radius, providing a tactile, pill-adjacent touch surface without losing rectangular architectural structure.
- **Micro Tags & Numeric Badges (`rounded-md`):** `0.375rem` (6px) to maintain sharp definition at miniature scales.
- **Icon Enclosures:** Concentric circles or continuous squircles with 28% curvature.

## Components

### Buttons
- **Primary Action (Brand CTA):** Background `#0F766E` (`brand-700`), text `#FFFFFF`, height 48px, radius `12px`. Hover/active shifts to `#115E59` (`brand-800`). Never use bright gradients on simple operational buttons.
- **Secondary / Ghost Action:** Background `#F1F5F9`, text `#0F172A`, border `1px solid transparent`. Active state adds `border-color: #CBD5E1`.
- **Destructive Trigger:** Background `#FFF1F2`, text `#E11D48`, border `1px solid #FFE4E6`.

### Cards & Ledger Blocks
- **"Daily Safe Spend" Hero Card:** Driven by `linear-gradient(135deg, #14B8A6 0%, #06B6D4 100%)`. Content inverted: figures in `#FFFFFF`, sub-captions in `rgba(255, 255, 255, 0.85)`. Contains embedded micro progress bar showing remaining daily allowance.
- **Ledger Row Card:** Pure white `#FFFFFF` surface, `16px` padding, containing:
  - Left: 40px squircle category icon container in `#F0FDFA` with `#0D9488` SVG icon.
  - Middle: Primary transaction title in `#0F172A` (`body-md`, bold) and dynamic budget impact pill underneath (e.g., "Dining: 42% left").
  - Right: Expense amount strictly in `#0F172A` (`numeric-data`). Positive incomes rendered in `#0D9488`.

### Input Fields & Keypad
- **Amount Entry Field:** Fluid massive typography using `numeric-hero`. Background transparent or `#F8FAFC`, zero external border except a bottom baseline indicator in `#0D9488` when active.
- **Standard Input:** Background `#F8FAFC`, border `1px solid #E2E8F0`, text `#0F172A`, placeholder `#94A3B8`. Focused state switches border to `2px solid #0D9488` with no harsh shadow.

### Chips & Micro Status Indicators
- **Category Filter Chips:** Height 32px, `rounded-lg`. Inactive: background `#F1F5F9`, text `#64748B`. Active: background `#CCFBF1`, text `#0F766E`, font weight 600.
- **Budget Health Badges:**
  - Healthy (0–70%): `#F0FDFA` fill, `#0D9488` text.
  - Caution (71–99%): `#FFFBEB` fill, `#F59E0B` text.
  - Overspent (100%+): `#FFF1F2` fill, `#E11D48` text.

### Dedicated Component: Budget Penetration Bar
Embedded directly into transaction input and category summary lists:
- A multi-segment horizontal gauge (height 6px, radius 9999px) with background track `#E2E8F0`.
- Left-to-right fill represents current budget position, while a projected translucent ghost segment previews the exact impact of the pending input before final confirmation.
